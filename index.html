幻想の魔導書

Grimoire Fantasia

宝箱に眠る魔導書を集め、杖に宿し、
合成台で新しい魔法を編み出す。

ダウンロード どんな MOD？
  • Minecraft 1.21.1
  • NeoForge 21.1.251〜
  • バージョン 1.0.0

特徴

魔導書で魔法を唱える

魔法は一冊の魔導書に閉じ込められています。右クリックするだけで、灯・氷・風・毒・火・雷・爆発…さまざまな魔法が出ます。使うたびにマナを消費し、紙は少しずつ擦り切れていきます。

杖に宿して強くする

壊れた杖に魔導書を重ねると、魔法が杖へ移ります。杖は魔導書より遠くまで届き、強く、何倍も長く使えます。右クリックを長押しして「ためる」杖もあります。

合成台で新しい魔法を編む

魔導書どうしをコアでつなぐと、まったく新しい魔導書が生まれます。聖火・瘴爆・暴爆・黒雷・吹雪など、宝箱では手に入らない強力な魔法が 7 種類。

マナを育てる

魔法使いの装束を着る、マナのポーションを飲む、マジックソウルを取り込む。最大マナと回復の速さを伸ばして、より多くの魔法を使えるようになります。

ダンジョンとボス

沼の小屋、氷の塔、空に浮かぶ島、地下 4 層の遺跡。遺跡の最深部では、聖騎士シンシアが目を覚まします。

使い魔と冒険する

羽根や毛糸、帽子に宿る使い魔を呼び出して、一緒に戦ってもらえます。暗視や落下ダメージ無効など、主人を助ける力を持つ使い魔も。

困ったら「魔法使いの手記」を。 村の宝箱や魔法使いの家に入っている手記には、この MOD のことがすべて書かれています（全 118 ページ）。

魔導書と杖

アイコンを押すと、くわしい説明が開きます。数値はゲーム内の値です。

アンコモン レア エピック ／ 杖の作り方：作業台の上段中央に魔導書、中段中央に壊れた杖

合成台

合成台は、いくつかの魔導書を重ねて新しい一冊に編み直すための台です。上の 3 マスに魔導書を、その下のマスに「コア」を置くと、右のマスに新しい魔導書が現れます（並べる順番は関係ありません）。

コアは、色ごとのメイジが 5% の確率で落とします。イエローコアは聖騎士シンシアも 50% で落とします。

    装束とマナ

    マナのしくみ

    魔法を使うたびにマナが減り、何もしなくても毎秒およそ 2 ずつ戻ります。マナのバーは画面下、経験値バーのすぐ下に出ます。足りないときは魔法が出ず、杖の耐久も減りません（クリエイティブではマナを使いません）。

    • 最大マナは初め 100。
    • マジックソウル：右クリックで最大マナ +20（1 人 20 回まで・死んでも失われない）。古い宝箱にまれに入っています。
    • マナのポーション：奇妙なポーション＋クレイルの実。マナ再生 VI（3 分）。レッドストーンで 8 分、グロウストーンで XI（1 分半）。
    • クレイルの実：生のまま食べると 10 秒だけマナの戻りが速くなります。土に植えると育ちます。

    魔法使いの装束（3 組）

    メイジたちの弾や多くの魔法は、鎧の防御力を素通りする「魔法ダメージ」です。装束に付いている魔法防御だけがそれを軽くします。

    生き物

    メイジには 6 色の同族がいて、住む場所で放つ魔法が変わります。倒すと 10% で「壊れた杖」を、色つきのメイジは 5% でコアを落とします。

    BOSS

    聖騎士シンシア

    地下遺跡の最深部、円い大広間で眠る聖騎士。はじめて足を踏み入れた者の前で、魔法陣から目を覚まします（ひとつの遺跡で一度だけ）。

    • 体力 3000。聖剣の斬撃、光の斬撃・光の槍・光の柱、聖なるウサギの召喚、張り付くと光の波で吹き飛ばしてきます。
    • 体力が半分を切ると技が速くなり、光の雨を降らせます。
    • 光の槍・柱・波・雨は魔法ダメージ。魔法防御で軽くなります。

    使い魔

    小さな品に宿る使い魔。品を持って右クリックで呼び出し、もう一度でしまえます。品は消耗せず、一度に連れていられるのは 1 種類だけ。主人が右クリックすると「おすわり」と「ついていく」を切り替えます。

    使い魔が倒れると、その品は 1 分のあいだ眠ります（そのあとは元気な姿で呼べます）。品が持ち物から離れると、使い魔はひとりでに品へ帰ります。

    ダンジョン

    魔導書は、ここに挙げた場所のほか、廃坑・ダンジョン・森の洋館・要塞・ネザー要塞・砦の遺跡・エンドシティ・難破船・古代都市などバニラの宝箱にも入ります（1 つの宝箱に 1 冊以上入る確率 約 42%）。

    導入方法

    1. NeoForge を入れる

      NeoForge 公式サイトから Minecraft 1.21.1 用のインストーラー（21.1.251 以降）をダウンロードして実行し、「Install client」でインストールします。

    2. MOD をダウンロードする

      下のボタンから、いちばん新しい grimoirefantasia-◯.◯.◯.jar をダウンロードします。

      GitHub Releases を開く

    3. mods フォルダに入れる

      ランチャーで NeoForge のプロファイルを一度起動してから閉じ、.minecraft/mods フォルダに jar ファイルを入れます。

    4. 遊ぶ

      NeoForge のプロファイルで起動し、タイトル画面の「Mods」に Grimoire Fantasia があれば完了です。まずは村で「魔法使いの手記」を探してみてください。

    設定：ワールドに入った状態で「Mods → Grimoire Fantasia → 設定」から、魔法がほかのプレイヤーや友好モブに当たるかどうかを切り替えられます（初期値はどちらも OFF）。マルチプレイではサーバー側の設定が使われます。

    Q&A

    マルチプレイで使えますか？

    はい。サーバーとクライアントの両方に同じバージョンの MOD を入れてください。

    魔法が自分や味方に当たることは？

    唱えた本人・同じチーム・自分のペットと使い魔には当たりません。ほかのプレイヤーと友好モブに当たるかは設定で切り替えられます。

    魔導書や杖は修理できますか？

    できません。擦り切れたら、また探すか作り直してください。壊れた杖は多めに集めておくと安心です。

    前のバージョン（OchiMod）のワールドは使えますか？

    MOD の ID が変わったため、前の名前（ochimod）のころのアイテム・ブロック・生き物・建物は引き継げません。新しいワールドで遊んでください。

    ほかの MOD といっしょに使えますか？

    多くの場合は大丈夫ですが、すべての組み合わせは確かめていません。問題があれば GitHub の Issues で教えてください。

特徴

魔導書で魔法を唱える

魔法は一冊の魔導書に封じられている。右クリックするだけで、灯・氷・風・水・火・雷・爆発など、様々な魔法が発動する。地面を削る整地、作物を育てる成長、鉱石を探す魔法など、暮らしに役立つものも多い。使うたびにマナを消費し、紙は少しずつ擦り切れていく。

杖に宿して強くする

壊れた杖に魔導書を重ねると、魔法が杖に宿る。杖は魔導書よりも射程が長く、威力も増し、耐久力も何倍も高い。右クリック長押しで魔力を「ためる」杖も存在する。

合成台で新しい魔法を編む

魔導書同士をコアでつなぐと、新たな魔導書が生まれる。聖火・吹雪・黒雷・慈光・酸など、宝箱からは手に入らない9種類の魔法が存在する。

マナを育てる

魔法使いの装束を着る、マナのポーションを飲む、マジックソウルを取り込むことで、最大マナと回復速度が上昇する。これにより、さらに多くの魔法を操れるようになる。

ダンジョンとボス

沼地の小屋、氷の塔、空に浮かぶ島、海にそびえる大海の塔、山岳の火山、根の張りめぐらされた巨大樹の迷宮、荒野の雷獣の渓谷、地下8層の聖なる遺跡、地下10層の魔獣の遺跡。その奥では強力なボスたちが待ち受ける。

使い魔と冒険する

羽根や毛糸、帽子、卵や魂に宿る使い魔を呼び出し、共に戦うことができる。暗視や落下ダメージ無効など、主人をサポートする能力を持つ使い魔もいる。

困ったときは「魔法使いの手記」を読もう。村の宝箱や魔法使いの家にある手記には、魔導書や杖、合成、装束、メイジ、使い魔、探索場所など、このMODの遊び方が記されている（全124ページ）。ただし、遺跡の最深部については、手記の持ち主すら知らない。

魔導書と杖

アイコンを押すと詳細な説明が開く。数値はゲーム内の値に基づく。

アンコモン レア エピック ユニーク レジェンダリー ／ 杖の作り方：作業台の上段中央に魔導書、中段中央に壊れた杖

合成台

合成台は、複数の魔導書を重ねて新たな一冊を編み出すための台だ。上の3マスに魔導書、その下のマスに「コア」を配置すると、右のマスに新しい魔導書が完成する（並べる順番は問わない）。

コアは、基本的にボスたちから手に入る。色ごとのメイジも1%の確率で落とすほか、精霊やシェルクラブ、サンダーエレメントは5%の確率で落とす（右の一覧を参照）。ただし、モンスタースポナーから湧いた敵はコアを落とさない。

→

板材（種類不問）で上下をはさみ、中段に布・マナのかけら・布を配置する。

合成台は村人の職業ブロックにもなる。村に合成台があれば、村人の一人が「魔法使い」となり、マナのかけらとコンパスを渡すことでダンジョンの地図と交換してくれる（詳細は「生き物」の項目を参照）。

コア

    合成の流れ

    左の魔導書を、矢印の途中にあるコアといっしょに合成台へ置くと、右の魔導書ができる。線の色はコアの色。魔導書やコアにカーソルを合わせると、つながっている線だけが光る（クリックで詳しい説明）。

    合成レシピ（9 種）

    装束とマナ

    マナのしくみ

    魔法を使うたびにマナを消費し、何もしなくても毎秒およそ2ずつ自然回復する。マナゲージは画面下部、経験値バーのすぐ下に表示される。マナが足りない場合は魔法が発動せず、杖の耐久値も減らない（クリエイティブモードではマナを消費しない）。

    • 初期の最大マナは 100。
    • マジックソウル：右クリックで最大マナ +20（1 人 20 回まで・死んでも失われない）。古い宝箱に稀に入っている。
    • マナのポーション：奇妙なポーション＋クレイルの実。マナ再生 VI（3 分）。レッドストーンで 8 分、グロウストーンで XI（1 分半）。
    • クレイルの実：生のまま食べると10秒間だけマナの回復が早くなる。土に植えれば栽培可能。

    魔法使いの装束（3 組）

    メイジの弾や多くの魔法は、鎧の防御力を無視する「魔法ダメージ」となる。装束に付与された「魔法防御」でのみ、ダメージを軽減できる。

    生き物

    メイジには6色の同族が存在し、生息地によって放つ魔法が異なる。倒すと10%の確率で「壊れた杖」を、色付きのメイジは1%の確率でコアをドロップする。遺跡には精霊が、海辺にはカニが生息している。村に合成台を設置すれば、地図を交換してくれる魔法使いの村人も現れる。

    使い魔

    小さなアイテムに宿る使い魔。アイテムを持って右クリックで召喚し、もう一度右クリックで戻せる。アイテムは消耗せず、一度に連れ歩けるのは1種類のみ。主人が右クリックすることで「待機」と「追従」を切り替えられる。

    使い魔が倒れると、そのアイテムは1分間休眠状態になる（その後は再び元気な姿で召喚可能）。アイテムがインベントリから離れると、使い魔は自動的にアイテムへと帰還する。

    ボス

    ボスは全10体。アイコンをクリックすると正体が現れ、詳細が表示される。8体はダンジョン奥のボス部屋に初めて足を踏み入れた際、魔法陣から出現する。倒すと進捗の「挑戦」が達成されるため、順番に挑むのがおすすめ。

    ダンジョン

    魔導書は、ここに挙げた場所のほか、廃坑、ダンジョン、森の洋館、要塞、ネザー要塞、砦の遺跡、エンドシティ、難破船、古代都市など、バニラの宝箱にも生成される（1つの宝箱に1冊以上入っている確率は約42%）。

    導入方法

    1. NeoForge を入れる

      NeoForge公式サイトからMinecraft 1.21.1用のインストーラー（21.1.251以降）をダウンロードして実行し、「Install client」を選択してインストールする。

    2. MOD をダウンロードする

      下のボタンから、最新の grimoirefantasia-◯.◯.◯.jar をダウンロードする。

      GitHub Releases を開く

    3. mods フォルダに入れる

      ランチャーでNeoForgeのプロファイルを一度起動して閉じ、.minecraft/mods フォルダにjarファイルを配置する。

    4. 遊ぶ

      NeoForgeのプロファイルで起動し、タイトル画面の「Mods」一覧に Grimoire Fantasia があれば導入完了。まずは村で「魔法使いの手記」を探してみよう。

    設定：「Mods → Grimoire Fantasia → 設定」から、魔法が他のプレイヤーや友好モブに当たるかどうかを切り替え可能（初期値はどちらもOFF）。タイトル画面でもワールド内でも変更でき、全ワールドで共通となる。EssentialやLAN公開時はホストの設定が、専用サーバーではサーバー側の設定が適用される。

    Q&A

    マルチプレイで使えるか

    可能。サーバーとクライアントの両方に同じバージョンのMODを導入すること。

    魔法が自分や味方に当たることは？

    唱えた本人、同じチーム、自分のペットと使い魔には当たらない。他のプレイヤーや友好モブに当たるかどうかは設定で切り替え可能。

    魔導書や杖は修理できるか

    不可。耐久値が尽きたら、新しく探すか作り直す必要がある。壊れた杖は多めに集めておくと安心だ。

    他のMODと一緒に使えるか

    代表的なものは動作確認済みだが、全ての組み合わせを検証しているわけではない。問題があればGitHubのIssuesへ報告してほしい。
